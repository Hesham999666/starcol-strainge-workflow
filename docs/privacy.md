# Data privacy and controlled data

This repository contains computational code, documentation and synthetic
example metadata only.

## Not included

The repository does not contain:

- REFIT2 participant identifiers;
- participant FASTQ files;
- participant HDF5 files;
- participant-level StrainGE output tables;
- clinical metadata;
- participant treatment-assignment tables;
- internal Saga/Sigma2 storage paths;
- internal data-transfer information.

## Public reference-isolate data

Raw whole-genome sequencing reads and draft genome assemblies for the
53 cultured Donor B bacterial isolates used to construct the StrainGE
reference database are deposited in the European Nucleotide Archive.

ENA study accession:

`PRJEB128176`

ENA record:

https://www.ebi.ac.uk/ena/browser/view/PRJEB128176

## Controlled REFIT2 data

REFIT2 participant metagenomic and associated clinical data are
participant-level research data and are not publicly distributed through
this repository.

Access to these data is governed by the REFIT2 data-sharing policy,
applicable ethical approvals and approval from the relevant study
investigators and data custodians.
